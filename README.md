# What Is n8n?

n8n is an open-source workflow automation platform that connects applications, APIs, databases, and cloud services using visual workflows.

Instead of writing custom integration code for every process, developers can automate tasks using reusable workflow nodes.

Typical use cases include:

* API integrations
* Data synchronization
* Business workflow automation
* AI-powered automation
* CRM automation
* Notifications
* Scheduled jobs
* File processing
